# Unidad-1-Ejercicio-7
Programacion 3 Unidad 1 Ejercicio 7
Ejercicio 7 — Ficha personal completa
En este ejercicio vas a integrar la mayor cantidad posible de componentes básicos vistos en la unidad dentro de un único formulario coherente. El desafío está en organizar visualmente todos los elementos de forma clara y ordenada.

Construí una ventana que represente una ficha de registro personal con los siguientes campos:

Etiqueta y campo de texto para Nombre completo
Etiqueta y campo de texto para Fecha de nacimiento (formato DD/MM/AAAA)
Etiqueta y JComboBox para Provincia, con al menos 6 opciones
Etiqueta y JComboBox para Nivel de estudios, con las opciones: Primario, Secundario, Terciario, Universitario, Posgrado
Etiqueta y dos JRadioButton agrupados para Estado civil: Soltero/a y Casado/a
Un JCheckBox con el texto "¿Tenés hijos?"
Un botón con el texto "Guardar ficha"
Un botón con el texto "Cancelar"
Organizá los componentes de forma que el formulario sea fácil de leer y completar. Cada etiqueta debe estar claramente asociada a su componente correspondiente.

💡 Tip: para este ejercicio conviene usar paneles anidados. Por ejemplo, un panel principal que contenga un panel para los campos del formulario y otro panel separado para los botones de acción.
